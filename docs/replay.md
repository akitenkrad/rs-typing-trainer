# Replaying session records

`replay` feeds the recorded keystrokes back through the normal session engine and renders the ordinary playing screen, including prompt progress, cursor, mistake feedback, next-key highlight, finger guide, time, and WPM. It does not open the session database or read the user's configuration. The portable record format is summarized in [Record format and metrics](records.md).

```sh
rs-typing-trainer replay examples/records/dvorak-sentence-en.ttrec
```

## Options

| Option | Effect |
|---|---|
| `--interval <MS>` | Replace every recorded keystroke interval with a fixed number of milliseconds. |
| `--speed <X>` | Play recorded timestamps at `X` times normal speed; default `1.0`. Cannot be combined with `--interval`. |
| `--paused` | Start paused. |
| `--exit-on-end` | Exit when the final keystroke has been applied. Without it, keep the completed final playing frame visible. |
| `--print` | Print mode, layout, prompts, counts, duration, and metrics without opening the TUI. |

The display language is still selected by the global option:

```sh
rs-typing-trainer --lang ja replay examples/records/dvorak-words-en.ttrec --speed 2
rs-typing-trainer replay examples/records/qwerty-romaji-ja.ttrec --print
```

During playback, `Space` pauses or resumes, `→` applies one keystroke, and `Esc`, `Q`, or `Ctrl-C` quits. Stepping also works while a replay is paused. A single status row shows replay progress and controls. At the end, the last completed prompt and keyboard remain on screen while that row changes to the final WPM and accuracy. Live and final metrics are calculated by the same log-based metric functions used for a played session; replay does not maintain a second scoring implementation.

## Sample records

The files in [`examples/records/`](../examples/records/) are synthetic, deterministic demonstrations generated by [`examples/gen_sample_records.rs`](../examples/gen_sample_records.rs). Their first header line identifies them as synthetic. The generator selects bundled prompts, uses fixed seeds, draws log-normal intervals with 150–200 ms medians, adjusts timing by physical transition class, and inserts occasional mistakes and corrections.

```sh
cargo run --locked --example gen_sample_records
```

## Recording video

With [asciinema](https://asciinema.org):

```sh
asciinema rec -c "rs-typing-trainer replay examples/records/dvorak-sentence-en.ttrec --exit-on-end" typing.cast
```

For [VHS](https://github.com/charmbracelet/vhs), use a tape like [`examples/demo.tape`](../examples/demo.tape). The rs-games catalog recording deliberately omits `--exit-on-end`, waits for the replay duration plus 3.5 seconds, and leaves the completed final playing frame visible in the GIF.
