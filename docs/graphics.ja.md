# 端末画像

起動時に端末画像を使えるか判定し，選んだ方式と 1 セルの画素数を保持します．文字による結果は `rs-typing-trainer graphics`，一時的な試験画像は `rs-typing-trainer graphics --demo` で確認できます．

## 方式

| 方式 | 特徴 |
|---|---|
| kitty graphics | 画像に番号を付けて 1 度送り，あとは置く場所の指示だけ．重なりの順も指定でき，差分の更新に強い． |
| Sixel | 毎回画像全体を送る．256 色程度．消すには上から描く． |
| iTerm2（OSC 1337） | PNG を base64 で毎回送る． |

## 端末ごとの対応

| 端末 | 使う方式 | 確かめ方 |
|---|---|---|
| Ghostty・kitty | kitty | Ghostty は 2026-11-15 に確認済み |
| WezTerm | kitty（Sixel・iTerm2 も可） | 3 方式の検証に使える |
| iTerm2 | iTerm2 | 要確認 |
| foot・Windows Terminal（1.22 以降） | Sixel | 要確認 |
| VS Code の端末 | iTerm2 か Sixel（設定で有効化） | 要確認 |
| macOS のターミナル・Alacritty | なし → ブロック文字・文字描画 | — |

この表は現在の設計上の想定です．«要確認» の項目は未確認のままです．

VHS の xterm.js は Sixel 対応を返しますが，canvas の録画には画像レイヤーが写らないため，tape 内では `--graphics off` を付けます．

## 判定規則

`auto` は `ratatui-image` を通して 1 回だけ問い合わせます．優先順は kitty，iTerm2，Sixel で，半ブロックは画像方式なしとして扱います．標準入出力が端末でなければ常に `off` です．tmux／screen 内の `auto` は passthrough を確かめられないため `off` とし，方式を明示した場合だけ利用を試みます．明示した方式では，問い合わせで得た 1 セルの画素数，端末全体の画素数÷列数・行数の順で使い，どちらも得られなければ `off` にします．

端末の大きさが変わったときは，問い合わせを送り直さず，端末全体の画素数から 1 セルの画素数を更新します．終了時の kitty 全画像消去は，キーボードプロトコルの後始末と代替画面の終了より前に送ります．

## キーキャップの画像描画

実際に使うキーボードの見た目が `keycap` で，画像方式を利用できる場合は，キーごとに独立した画像タイルを描きます．角丸の面・影・押し込み・東雲ビットマップのラベルを描き，指ガイドが有効なら面の下端に指の色の帯を加えます．次のキー，正誤，ヒートマップ，解放状態，フェードを含む色とラベルの判定には，文字版と同じ状態を使います．

タイルは見た目と端末の画素条件を組にしてキャッシュします．kitty は同じタイルを 1 度だけ送り，以後は置く場所だけを指示します．Sixel と iTerm2 は端末バッファの差分を使い，変わっていないセルを送り直しません．端末の大きさや方式が変わったときはキャッシュを捨てます．`raised`・`plain`，画像方式を使えない端末，`auto` の tmux／screen，端末でない出力では，従来の文字描画を使います．

## 出題の大きな文字

`display.prompt_style = "large"` で画像方式を利用できる場合は，出題の大きな文字も 1 字ずつ背景が透明なタイルで描きます．`display.big_font` では，同梱の BIZ UDゴシックの輪郭，整数倍に拡大する東雲のビットマップ，または利用者の TTF・OTF・TTC の 0 番目を選べます．文字の列位置・幅，色，太字，表示・非表示，カーソル，マーカーの判定は文字版と共通で，字形の箱だけを画像にします．全角の箱が正方形に近くなる行数を使うため，1 セル 9×20 px の Dot16 は，文字版の 8 行ではなく 4 行です．

利用者の書体に字が無ければ，その字だけ BIZ UDゴシック，東雲，従来の文字フォールバックの順で描きます．タイルはキーキャップと同じキャッシュ方針を使い，方式・1 セルの画素数が変わったときと上限に達したときに全件を捨てます．見えている窓は配置前に準備するため，通常の 1 打鍵では色が変わった字だけを新しく作ります．画像方式が無い場合は，従来の東雲ブロック描画をそのまま使います．
