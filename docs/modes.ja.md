# 訓練モードとローマ字入力

## モード

| モード | 出題 | キー選択 |
|---|---|---|
| `random` | `mode.keys` から作る擬似語 | 選択文字を文字集合として使う |
| `words` | 英単語 | `include` または `only` |
| `romaji` | 表記とかな読みを持つ日本語の単語 | 受理できるローマ字綴りに対する `include` または `only` |
| `sentence` | 英語または日本語の短文 | キー選択なし．`mode.sentence.lang` に `en` または `ja` を指定 |
| `ngram` | 2〜3 文字の遷移 | 選択キーの直積 `pairs`，または同梱データ中の `corpus` |
| `adaptive` | 弱い遷移を重み付けした実在の単語とドリル | 縮小推定から自動選択 |
| `unlock` | 解放済みのキーだけでできる単語と擬似語 | 自動選択し，レイアウトごとに保存 |
| `rhythm` | メトロノームの 1 拍に 1 打鍵で進む単語 | 自動選択 |
| `burst` | 10〜15 語の短距離を 3 本 | 自動選択 |
| `endurance` | 3〜5 分の短文 | キー選択なし．短文の言語を使う |

タイトルからモード選択を開きます．`words`，`romaji`，`ngram` では，続いてキーボード上のキー選択を開きます．矢印キーで移動し，`Space` で選択を切り替え，`Tab` で `include` / `only` を切り替え，`Enter` で開始します．選択結果は，関係のない TOML キーを書き換えずに `[mode]` へ保存します．

`include` は選択キーを 1 つ以上含む項目を残し，選択キーの出現回数で抽選を重み付けします．`only` は，選択キーと `base_keys` だけで入力できる項目を残します．`base_keys` には `none`，`home`，または任意の文字列を指定します．ローマ字では受理できる綴りが 1 つでも条件を満たせばよいため，`t` が無くても `chi` で入力できる「ち」は候補になります．`keys = ""` のとき，`words`，`romaji`，`sentence` はキーで絞り込みません．`random` と `ngram` はキー選択へ戻り，「キーを選んでください」と表示します．

候補に余裕がある間は，直近 10 項目を抽選から外します．候補が 20 未満なら警告します．擬似語で補うのは `words` と `only` の組み合わせだけで，選択したキーだけから作ります．`romaji`，`sentence`，`words` と `include` の組み合わせは，直近 10 項目の条件を緩めて実データの候補を繰り返します．

日本語の短文は，表記，かな，入力に追従するローマ字ガイドを別々に折り返して表示します．入力済みのかなは別のスタイルで示します．`sentence` では 1 項目の制限時間を適用しません．ほかのモードでも `item_timeout_seconds = 0` ならタイマーを表示しません．

`adaptive`，`unlock`，`rhythm`，`burst`，`endurance` は直接開始します．モード選択画面で `P` を押すと `words`，`sentence`，`adaptive` のペーサーを切り替えます．`adaptive` で `L` を押すと表示言語とは独立した練習言語を切り替え，`[` と `]` で先読みを 0〜3 項目から選びます．狙い，初期値，設定方法は[訓練機能](training.ja.md)を参照してください．

## 日替わり出題

練習モードは，決定的な日替わり出題を使います．同梱データの全件は，固定ベンチマーク向けに別の入口で保持します．`include` と `only` は，核と裾野に分ける前の全候補へ適用します．利用者ごとの乱数の塩をセッション DB に保存するため，別の環境では異なる出題になります．

既定は核65%です．以前に誤った項目は，最後の誤りから1・3・7・14日後に出題全体の最大10%まで戻します．短文は未出題を優先し，その後は出題回数の少ない順です．水曜は数字・記号，金曜は日本語の1人の作家，日曜は裾野50%を優先します．テーマはタイトルとモード選択に表示します．

```toml
[practice]
daily_rotation = true
core_ratio = 0.65
weekly_theme = true
```

`daily_rotation = false` なら，P3 の従来の抽選を使います．`romaji` または日本語の `sentence` のプレイ中に `F2` を押すと，読みの誤りを報告してその項目をすぐに飛ばし，次回以降は除外します．

## ローマ字の綴り

判定器は，入力済みの接頭辞に合う綴り候補をすべて保持します．表示ガイドは代表綴りから始まり，例えば `shi` に対して `s`，`i` と入力すると `si` へ追従します．読みのカタカナはひらがなへ直します．ASCII の英数字と記号はそのまま入力します．

| かな・分類 | 受理する綴り |
|---|---|
| し / ち / つ / ふ / じ | `shi si ci` / `chi ti` / `tsu tu` / `fu hu` / `ji zi` |
| か / く / こ / せ | `ka ca` / `ku cu qu` / `ko co` / `se ce` |
| ぢ / づ / ゔ / を | `di` / `du` / `vu` / `wo` |
| しゃ | `sha sya sixya silya shixya shilya`．`しゅ`・`しょ` も同形 |
| ちゃ | `cha tya cya chixya chilya tixya tilya`．`ちゅ`・`ちょ` も同形 |
| じゃ | `ja jya zya jixya jilya zixya zilya`．`じゅ`・`じょ` も同形 |
| その他の拗音 | `kya`，`nya`，`hya`，`mya`，`rya`，`gya`，`bya`，`pya` と，小書きかなを明示する形 |
| 小書きかな | `la/xa`，`li/xi`，`lu/xu`，`le/xe`，`lo/xo`，`lya/xya`，`lyu/xyu`，`lyo/xyo`，`lwa/xwa` |
| てぃ / でぃ | `thi texi teli` / `dhi dexi deli` |
| ふぁ / ふぃ / ふぇ / ふぉ | `fa fi fe fo` と，`fu`＋小書きかなを明示する形 |
| しぇ / じぇ / ちぇ | `she sye` / `je jye zye` / `che tye cye` と，小書きかなを明示する形 |
| っ | 次の綴りの先頭子音，または `ltu xtu ltsu xtsu` |
| ん | `n nn n' xn`．`n'` と `xn` は `[mode.romaji]` で切替 |
| ー / 、 / 。 / ？ / ！ | `-` / `,` / `.` / `?` / `!` |

母音・や行・な行・次の「ん」の前では，`n` 1 つで「ん」を確定しません．`nn`，`n'`，`xn` のいずれかを使います．語末の「ん」も明示的な確定が必要です．それ以外の子音の前では `n` と `nn` の両方を受理します．記号は子音のモーラではないため，「こうえん、」は `kouenn,` と `kouen',` を受理し，`kouen,` を拒否します．促音は，次の受理綴りの先頭子音を重ねます．「っち」では `cchi` と `tchi` の両経路を受理し，小書き「っ」を明示する綴りも常に使えます．

```toml
[mode.romaji]
accept_apostrophe = true
accept_xn = true
```

## 誤入力の扱い

`session.error_mode = "stop"` は，誤入力を記録してカーソルを進めません．`"advance"` は誤入力でも位置を進め，`Backspace` で戻れます．Backspace は `kind = "backspace"` として記録します．指標は編集後の最終バッファを再生して求めます．修正した誤りは未修正数に残らず，修正しなかった位置だけを net WPM と正確さから引きます．raw WPM は実際に押した文字キーをすべて数えます．

ブラインド練習では `advance` を強制します．`retry_on_error = true` では，誤打した項目を直後に 1 回だけ出し直します．ベンチでは両方を無効にし，固定の入力条件を維持します．

## 利用者のデータファイル

`data.words_en`，`data.words_ja`，`data.sentences_en`，`data.sentences_ja` のいずれかを指定すると，対応する同梱サンプルを置き換えます．空行と `#` で始まる行は無視します．

英語の単語と短文は UTF-8 TSV の 1 列です．

```text
quiet
river
```

日本語の単語と短文は `text<TAB>reading` の 2 列です．

```text
公園	こうえん
短い手紙を書く。	みじかいてがみをかく。
```
