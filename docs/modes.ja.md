# 訓練モードとローマ字入力

## 個別の訓練

個別の訓練は表です．行は**鍛える技能**，列は**打つもの**です．矢印キーか `h` `j` `k` `l` で升目を移り，`Enter` で始めます．表の下の 2 行に，その升目で何を鍛え，何を打つかを出します．

| 技能＼打つもの | 文字 | 組合せ | 単語 | 句 | 短文 | 長文 |
|---|---|---|---|---|---|---|
| ふつう | ○ | ○ | ○ | ○ | ○ | ○ |
| 正確さ・速さ・立ち直り・キーボードを見ない | ○ | ○ | ○ | ○ | ○ | ○ |
| 弱い遷移 | — | ○ | ○ | ○ | ○ | — |
| リズム | — | ○ | ○ | ○ | ○ | — |
| バースト | — | — | ○ | ○ | ○ | — |
| 持久 | — | — | ○ | ○ | ○ | ○ |
| キー解放 | ○ | — | ○ | — | — | — |

`—` の升目は薄く表示します．カーソルは止まり，選べない理由を表の下に出します．`Enter` を押しても始まりません．

### 技能（行）

| 技能 | 内容 | 当てる設定 |
|---|---|---|
| ふつう | 自分の設定のまま打つ | ペーサー無し |
| 正確さ | 誤打でカーソルが止まる．正確さ 97% 未満の回は順位に載らない | メニューの `accuracy.gate` の 1 段目（`session.error_mode = "stop"`，`gate.min_accuracy = 0.97`，ペーサー無し） |
| 速さ | 最近の速さより 5% 速いペーサーが問題の上を進む．どの列でも使える | `speed.pacer` の 1 段目（`pacer.enabled = true`，`pacer.ratio = 1.05`） |
| 立ち直り | 誤打しても先へ進み，間違えた問題をもう一度だけ打つ | `recovery.retry` の 1 段目（`session.error_mode = "advance"`，`session.retry_on_error = true`） |
| キーボードを見ない | 慣れたキーから画面の鍵盤が消えていく | `blind.fade` の 1 段目（`keyboard.show = "auto"`） |
| 弱い遷移 | 遅い・間違えやすいキーの移り変わりを多く打つ（`adaptive`） | ペーサー無し |
| リズム | メトロノームの 1 拍に 1 打鍵．結果に拍とのずれの中央値を出す（`rhythm`） | ペーサー無し |
| バースト | 短い区間を全力で 3 本．最も速い 1 本を記録（`burst`） | ペーサー無し |
| 持久 | `endurance.minutes`（3〜5 分）打ち続け，前半と後半を比べる（`endurance`） | ペーサー無し |
| キー解放 | 少ないキーから始め，最後に加えたキーが速くなったら 1 つ増やす（`unlock`） | ペーサー無し |

升目の設定は，今日の練習の段と同じく，その回だけのものです．設定のコピーに当てて使い，設定ファイルは変えません．次のセッションは利用者の設定に戻ります．結果画面で `Enter` を押すと，同じ升目をもう一度行います．

### 打つもの（列）

| 列 | 出題 |
|---|---|
| 文字 | 選んだキー（`mode.keys`）から作る擬似語．キー解放では解放済みのキーから作る |
| 組合せ | 選んだキーの 2〜3 文字の遷移（`mode.ngram`）．弱い遷移では，弱い遷移の反復ドリル |
| 単語 | 英単語，またはローマ字で打つ日本語の単語 |
| 句 | `C` で選んだコースの英語または日本語の句 |
| 短文 | 英語または日本語の 1 文 |
| 長文 | 英語は同梱の短文を 3〜5 文続けて 1 問にしたもの．日本語は青空文庫の同じ作品の文を本文の順につないだもの |

新しく選べるようにした升目の作り方:

- **弱い遷移 × 句・短文**: 適応練習の計画の重点遷移を多く含む句・文ほど出やすくします（重みは 1 + 4 × 含む回数）．重点遷移を含むものが 20 件以上あれば，含まないものは出しません．記録が足りないときは均等に出します．**弱い遷移 × 組合せ** は計画のドリルだけを出します．
- **リズム × 組合せ・句・短文**: メトロノームと拍のずれの測り方はそのままで，出題だけが変わります．
- **バースト × 句・短文**: 1 本は句 `burst.words` ÷ 3 個（既定 4 個），または短文 1 個です．単語の 1 本とほぼ同じ長さです．
- **持久 × 単語・句・長文**: 単語・句・長文で，同じく前半と後半を比べます．

句・短文・長文は，どの行でも 1 項目の制限時間を使いません．同梱の短文と長文は，問題文の下に出典（Tatoeba の番号，または青空文庫の作品）を出します．

### 練習言語

表には練習言語が 1 つあり，表の上に出します．`L` で全升目の言語を英語⇄日本語に切り替えます．単語は `words`⇄`romaji` に，`mode.sentence.lang`・`mode.phrase.lang`・`adaptive.lang` も揃えて変わります．文字・組合せ（弱い遷移を除く）・キー解放はいつも英字で打ち，英語として記録します．言語と升目は `[drill]` と `[mode]` に保存し，次に起動したときも同じ升目と言語で開きます．

### その他のキー

`W` で今日の練習の 1 分のウォームアップを，練習言語で単独に行います（[ウォームアップだけを行う](training.ja.md#ウォームアップだけを行う)を参照）．句の列にカーソルがあるとき，`C` でコースを短い／普通／長い／混合の順に切り替えます．英語の長さは 10〜15，16〜22，23〜29 表示文字，日本語は 6〜10，11〜15，16〜20 読み文字です．混合は短い 5 件，普通 5 件，長い 5 件をこの順で繰り返します．`[` と `]` で先読みを 0〜3 項目から選び，`Z` で問題文の表示を大きな文字と通常の文字で切り替えます．

### 記録

升目は表ができる前と同じ `mode` で記録します．履歴と分析の系列はそのまま続きます．ふつう × 単語は `words`（日本語なら `romaji`），ふつう × 短文は `sentence`，リズム × 単語は `rhythm`，持久 × 短文は `endurance` です．正確さ・速さ・立ち直り・キーボードを見ないは，列のモード（`random`，`ngram`，`words`/`romaji`，`phrase`，`sentence`）で記録します．ふつう × 長文は `sentence` です．どの升目も `mode_params` に `drill`（`{"skill", "unit"}`）と `unit` を書くので，短文で行ったリズムと単語で行ったリズムを見分けられます．データベースの形は変えていません．

## キー選択

文字・組合せと，上の 5 行の単語の升目は，始める前にキーボード上のキー選択を開きます（文字はキーが未選択のときだけ）．矢印キーで移動し，`Space` で選択を切り替え，`Tab` で `include` / `only` を切り替え，`Enter` で開始します．選択結果は，関係のない TOML キーを書き換えずに `[mode]` へ保存します．

`include` は選択キーを 1 つ以上含む項目を残し，選択キーの出現回数で抽選を重み付けします．`only` は，選択キーと `base_keys` だけで入力できる項目を残します．`base_keys` には `none`，`home`，または任意の文字列を指定します．ローマ字では受理できる綴りが 1 つでも条件を満たせばよいため，`t` が無くても `chi` で入力できる「ち」は候補になります．`keys = ""` のとき，単語はキーで絞り込みません．文字と組合せはキー選択へ戻り，「キーを選んでください」と表示します．

候補に余裕がある間は，直近 10 項目を抽選から外します．候補が 20 未満なら警告します．擬似語で補うのは `words` と `only` の組み合わせだけで，選択したキーだけから作ります．`romaji`，`sentence`，`words` と `include` の組み合わせは，直近 10 項目の条件を緩めて実データの候補を繰り返します．

日本語の短文・長文・句は，表記，かな，入力に追従するローマ字ガイドを別々に折り返して表示します．入力済みのかなは別のスタイルで示します．時間を使うモードでは，`item_timeout_seconds = 0` ならタイマーを表示しません．狙い，初期値，設定方法は[訓練機能](training.ja.md)を参照してください．

## 日替わり出題

練習モードは，決定的な日替わり出題を使います．同梱データの全件は，固定ベンチマーク向けに別の入口で保持します．`include` と `only` は，核と裾野に分ける前の全候補へ適用します．利用者ごとの乱数の塩をセッション DB に保存するため，別の環境では異なる出題になります．

既定は核65%です．以前に誤った項目は，最後の誤りから1・3・7・14日後に出題全体の最大10%まで戻します．句と短文は未出題を優先し，その後は出題回数の少ない順です．水曜は数字・記号，金曜は日本語の1人の作家，日曜は裾野50%を優先します．テーマはタイトルと個別の訓練の画面に表示します．

```toml
[practice]
daily_rotation = true
core_ratio = 0.65
weekly_theme = true
```

`daily_rotation = false` なら，P3 の従来の抽選を使います．日本語の単語や文のプレイ中に `Ctrl+R`（または `F2`）を押すと，読みの誤りを報告してその項目をすぐに飛ばし，次回以降は除外します．

## ローマ字の綴り

判定器は，入力済みの接頭辞に合う綴り候補をすべて保持します．表示ガイドは代表綴りから始まり，例えば `shi` に対して `s`，`i` と入力すると `si` へ追従します．読みのカタカナはひらがなへ直します．ASCII の英数字と記号はそのまま入力します．

| かな・分類 | 受理する綴り |
|---|---|
| し / ち / つ / ふ / じ | `shi si ci` / `chi ti` / `tsu tu` / `fu hu` / `ji zi` |
| か / く / こ / せ | `ka ca` / `ku cu qu` / `ko co` / `se ce` |
| ぢ / づ / ゔ / を | `di` / `du` / `vu` / `wo` |
| しゃ | `sha sya sixya silya shixya shilya`．`しゅ`・`しょ` も同形 |
| ちゃ | `cha tya cya chixya chilya tixya tilya`．`ちゅ`・`ちょ` も同形 |
| じゃ | `ja jya zya jixya jilya zixya zilya`．`じゅ`・`じょ` も同形 |
| その他の拗音 | `kya`，`nya`，`hya`，`mya`，`rya`，`gya`，`bya`，`pya` と，小書きかなを明示する形 |
| 小書きかな | `la/xa`，`li/xi`，`lu/xu`，`le/xe`，`lo/xo`，`lya/xya`，`lyu/xyu`，`lyo/xyo`，`lwa/xwa` |
| てぃ / でぃ | `thi texi teli` / `dhi dexi deli` |
| ふぁ / ふぃ / ふぇ / ふぉ | `fa fi fe fo` と，`fu`＋小書きかなを明示する形 |
| しぇ / じぇ / ちぇ | `she sye` / `je jye zye` / `che tye cye` と，小書きかなを明示する形 |
| っ | 次の綴りの先頭子音，または `ltu xtu ltsu xtsu` |
| ん | `n nn n' xn`．`n'` と `xn` は `[mode.romaji]` で切替 |
| ー / 、 / 。 / ？ / ！ | `-` / `,` / `.` / `?` / `!` |

母音・や行・な行・次の「ん」の前では，`n` 1 つで「ん」を確定しません．`nn`，`n'`，`xn` のいずれかを使います．語末の「ん」も明示的な確定が必要です．それ以外の子音の前では `n` と `nn` の両方を受理します．記号は子音のモーラではないため，「こうえん、」は `kouenn,` と `kouen',` を受理し，`kouen,` を拒否します．促音は，次の受理綴りの先頭子音を重ねます．「っち」では `cchi` と `tchi` の両経路を受理し，小書き「っ」を明示する綴りも常に使えます．

```toml
[mode.romaji]
accept_apostrophe = true
accept_xn = true
```

## 誤入力の扱い

`session.error_mode = "stop"` は，誤入力を記録してカーソルを進めません．`"advance"` は誤入力でも位置を進め，`Backspace` で戻れます．Backspace は `kind = "backspace"` として記録します．指標は編集後の最終バッファを再生して求めます．修正した誤りは未修正数に残らず，修正しなかった位置だけを net WPM と正確さから引きます．raw WPM は実際に押した文字キーをすべて数えます．

ブラインド練習では `advance` を強制します．`retry_on_error = true` では，誤打した項目を直後に 1 回だけ出し直します．ベンチでは両方を無効にし，固定の入力条件を維持します．

## 利用者のデータファイル

`data.words_en`，`data.words_ja`，`data.sentences_en`，`data.sentences_ja` は，対応する同梱カテゴリを置き換えます．`data.phrases_en` と `data.phrases_ja` は同梱の句へ利用者の句を追加し，重複時は同梱側を残します．空行と `#` で始まる行は無視します．

英語の単語・句・短文は UTF-8 TSV の 1 列です．

```text
quiet
river
```

日本語の単語・句・短文は `text<TAB>reading` の 2 列です．

```text
公園	こうえん
短い手紙を書く。	みじかいてがみをかく。
```
