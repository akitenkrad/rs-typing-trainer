# rs-typing-trainer の遊び方

## セッションの開始

`rs-typing-trainer` または `cargo run --release` を実行すると，タイトル画面が開きます．表示言語の既定は英語です．日本語にするには `--lang ja` を使います．`--config PATH` を指定すると，通常の検索先の代わりにその設定ファイルを読みます．

端末画像を利用でき，窓に十分な広さがある場合，タイトル画面の中央に，選択中のテーマと大きなフォントで描いた 2 段のキーキャップロゴを表示します．画像を無効にした場合や利用できない場合，または窓が狭い・低い場合は，すべての項目を残すため文字のロゴを使います．

タイトルの枠の右上には，アプリの短いバージョンを表示します．«終了» の直前にある «このアプリについて» を選ぶか，タイトル画面で `?` を押すと，このアプリについての画面が開きます．バージョン・コミット・ビルド日・対象環境，ライセンス・リポジトリ，内部データの版，設定・データベースの保存先，端末画像・キー解放の対応，同梱データの主な出典とライセンスを確認できます．

サブコマンドなしの起動は `rs-typing-trainer play` と同じです．`replay FILE` は可搬記録を再生し，`stats` は保存済みセッションを分析し，`graphics` は端末画像の判定を表示し，`export SESSION_ID [-o FILE]` は v2 セッションを `.ttrec` として書き出します．`-o` を省略すると標準出力を使います．リプレイは記録ファイルだけを読みます．詳しくは[リプレイ](replay.ja.md)を参照してください．

## 端末画像の確認

`rs-typing-trainer graphics` は，選んだ方式，1 セルの画素数，判定理由，`TERM`，`TERM_PROGRAM`，tmux・screen・SSH の有無を表示します．`--lang` に従い，`display.graphics` を読み，全体オプション `--graphics auto|kitty|sixel|iterm2|off` で上書きできます．

`rs-typing-trainer graphics --demo [--seconds N]` は代替画面を開き，選んだ方式で約 40×12 セルのグラデーション・1 画素幅の格子・四隅の印を表示します．既定では 3 秒後，またはキー入力で終了します．画像を使えない場合は理由を文字で表示します．この診断を加えた段階では，通常のゲーム画面の描画はまだ変わりません．詳しくは[端末画像](graphics.ja.md)を参照してください．

単語が入る途中と出る途中の各約 200 ms は，打鍵を捨てます．1 つの単語を終えた打鍵が，次の単語の入力として数えられるのを防ぐためです．

今日保存した最新のベンチ版に未完了の必須パートがあれば，ベンチ選択画面の先頭に，同じ版番号で最初の欠けたパートから続ける項目を表示します．A〜C がそろえば完了であり，任意の D が無くても再開対象にはしません．通常の新規開始も残り，版番号は従来の巡回規則で決めます．

## プレイ画面の配置

プレイ画面は上から順に，ヘッダ（時間・WPM・項目数・ペース），キーボード，項目タイマーのバー，連続正解・誤入力・正確さの行，出題，最下行の次の項目と操作説明です．出題は連続正解の行の直下から始め，キーボードより下の領域の上下中央には寄せません．左右は中央のままです．

同梱の短文（`sentence`・`endurance`）では，問題文の下に出典を控えめな色で 1 行出します．日本語は `作者『作品名』（青空文庫）`（表示言語が英語のときは `作者, "作品名" (Aozora Bunko)`），英語は `Tatoeba #12345` です．出すのは打っている問題だけで，次の項目の先読みには出しません．単語・句と，`[data]` で指定した自分のファイルの文には出典を出しません．余っている行が無いときは，問題の詰められる空き行を 1 行使うか（大きな文字），カード下の行を結果の表示と分け合います（通常の文字）．それもできなければ出典の行を省き，問題文・連続正解などの行・最下行は削りません．

`display.prompt_style` で問題文の描き方を `large`（既定）と `normal` から選びます．設定画面では «問題文の表示»（値は «大きな文字» と «通常の文字»）として表示し，個別の訓練の画面の `Z` でも切り替えられます．

**大きな文字** は，打っている項目を同梱した東雲ビットマップフォントで描きます．4個のフォントドットを端末の4分割ブロック文字1セルへ変換するため，12ドットの全角1字は6×6セル，16ドットは8×8セルです．大きな字形のブロックと，その前後の通常の大きさの行の間には 1 行ずつ空きを入れます．ラベルは独立した行にせず，対応するブロックの左隣の列，ブロックの最上段に置きます．

- 句を含む英語の項目モード: 大きな項目と下線 `▔` のカーソル．場所があれば，空き行のあとに補助行（ロック中，誤入力の内容，この項目の誤入力数，結果）を出します．
- 日本語の句を含むローマ字モードと，今日の訓練で単語系のモード（`words`・`ngram`・`unlock`・`rhythm`・`burst`．ウォームアップなど）を使う日本語の段: 大きな表記 → 空き → かな（太字・強調色．今の音を反転）→ 空き → 大きなローマ字とカーソル．ラベル（表記・かな・ローマ字）は左の列にそろえ，各ブロックは同じ列から始めます．
- `sentence` と `endurance`: 現在位置の前後を大きな窓で表示し，カーソル → 空き → 全文（通常の大きさ．今の位置を反転）の順に並べます．日本語の短文は上のローマ字と同じ並びのあと，空きを挟んで全文の表記・かな・ローマ字の 3 段を出します．

高さが足りないときは空き行から先に詰め，字形は削りません．ペーサーとゴーストの印は，対応する大きな文字の上に置きます．ブラインドモードでは入力済みの大きな字形を空白にします．大きな文字は，外枠の内側に左右 1 列ずつの余白を残して描きます．端末のフォントに4分割ブロック文字（U+2596〜U+259F と U+2580〜U+2590）が必要です．端末が1セルより幅の広い代替フォントで描くと大きな文字の行が枠より広く見えることがあり，その場合は `display.prompt_style = "normal"` で避けられます．フォントに無い文字（JIS X 0208 と ASCII・半角カナの範囲外）は，その字だけ通常の大きさで大きな枠の中央に置きます．

大きな文字の大きさは端末に合わせて自動で選びます．16ドット＋選択したキーボード，12ドット＋同じキーボード，12ドット＋簡素なキーボード，12ドット＋キーボード非表示の順に試し，どれも入らなければ通常の文字で（入るキーボードと一緒に）表示します．出題と操作説明は省きません．`keyboard.show = "hidden"` では，高さにかかわらずキーボード領域を省いて詰めます．

**通常の文字** は，端末の文字の大きさのまま，丸角の罫線（`╭╮╰╯`）で囲んだカードに入れ，連続正解などの行の直下・左右中央に置きます．カードの内側には左右 2 列・上下 1 行の余白を取ります．未入力の文字は明るい色の太字，今の文字は反転（誤入力の点滅中は赤の背景），入力済みの文字は落ち着いた色です．項目モード（words・英語の phrase・random・ngram・adaptive・unlock・rhythm・burst）は文字の間に 1 セルの空きを入れ，カーソル `▲` を今の文字の真下に置きます．日本語の句を含むローマ字モードは左の列にラベル（薄い色），右の列に本文を置く 2 列で，表記（太字）・かな・ローマ字の 3 段を 1 行ずつ空けて並べ，今の音・今の文字を反転します．短文は本文をカードの中で折り返し，今の行を明るく，それ以外の行を少し暗くし，今の行の直下にカーソルの行を置きます．日本語の短文は上の 3 段で，各段を折り返します．ペーサーとゴーストの印は文字の真上の行に置き，補助のメッセージはカードの下に出します．adaptive では，今の重点遷移をキーボード上の色付きの `①`，`②` の順で示します．通常の文字ではキーボードよりカードを優先し，キーボードを先に簡素化・非表示にします．それでも足りない小さな端末では，カードの空き行・余白・枠の順に省き，文字は最後まで残します．

## 結果画面

端末画像を利用でき，窓に十分な広さがある場合，結果画面は選択中のテーマで描いた 4 種類の画像をキャッシュして表示します．WPM・CPS・正確さは，選択した大きなフォントによる数値カードです．取得できるカードには，同じ条件の直前の記録との差と自己ベストとの差を添えます．値が高い場合は緑系の上向き印，低い場合は誤打色の下向き印です．WPM カードには，表示中の記録を含む同条件の最近 10 回までの折れ線も表示します．履歴詳細では，選んだ記録より後の記録を直前値や最近の折れ線へ混ぜません．

中央には，項目ごとの打鍵速度と反応時間の分布を表示します．項目の速度は，その項目で正しく打った文字キー数を 5 で割り，さらに項目の完了時間を分単位へ直した値で割った WPM です．全体 WPM の水平線を引き，誤打を含む項目には誤打色の点を付けます．利用できる完了項目が 2 件未満なら，データ不足と表示します．反応時間は 0.1 秒刻みで，1.5 秒以上を最後の棒へまとめ，p50・p90 の線を重ねます．

下段のキーボード図は，誤って期待された文字を設定中の配列へ対応づけ，回数を色の濃さで表します．回数の多い上位 3 キーには回数を添えます．配列へ対応づけられない文字列は `ほか N 件` として示します．誤打がなければ，従来の完璧な結果を示す文を残します．今回の気づきはキーボード図の右へ置き，気づきがある場合も上段の反応時間の分布を消しません．

端末画像を無効にした場合や利用できない場合は，同じ情報を文字で表示します．窓が狭い場合や低い場合も，入らない図を文字へ戻します．文字表示の誤打棒には `▆` を使って行間を空け，気づきがあっても反応時間の分布を表示します．ベンチのパート結果は専用の比較画面を保ち，適応訓練の詳細と履歴条件もそれぞれの結果画面に残します．

### 振り返り

プレイ直後の結果で `D` を押すと，全画面の振り返りを開きます．ベンチの結果にはこのページを出しません．`↑`/`↓` または `PageUp`/`PageDown` でスクロールし，`D` または `Esc` で結果へ戻ります．`Enter` は結果画面と同じ動作です．メニューでは次の段を始め，個別の訓練では説明をもう一度出さずに同じ訓練のカウントダウンを始めます．

振り返りでは，最初に段または升目の名前を示し，その回に目標があれば結果・線・判定を並べます．線との差，利用できる場合は前回・自己ベストとの差，メニューの卒業の進み具合，WPM・CPS・正確さ・誤打数も示します．結果に根拠があれば，良かった点を最大 3 件続けます．改善点は優先度の高いものを最大 3 件選び，数値を添えた «何が起きたか» と，具体的な «次にどうするか» を対にして出します．目標の達成，正確さ，最も多い最初の誤打の分類，最も多く誤打した期待キー，後半の遅れを利用できます．最後に次回やることを示し，メニューの段では卒業までに必要な成功回数も添えます．ふつうの行も振り返りを開けますが，目標の節は表示しません．

最後のベンチパートの後に出すまとめ画面は，利用できる高さを 3 段で使います．上段は今回の段階と構成ごとの段階，完了した各パートのカードです．カードには WPM・正確さ・前回差・以前の自己ベストとの差・短い版 ID を表示します．中段は各パートの最近 20 回までを WPM と正確さの 2 本の線で示し，今回の点を大きくします．A・C では `v2` の切れ目で線を結びません．下段は今回の全パートで誤打した期待キーを合算した図と，必要回数を満たす遅いつなぎ上位 5 件，弱い指 1〜2 本，前回から良くなった点・悪くなった点，具体的な練習案 1〜3 件です．有効な既存のつなぎの処方があれば，それを優先します．

場所が足りなくなると，過去の傾向，誤打キーボード，段階のバッジ，パートのカードの順に画像を文字へ戻します．文字表示でも，段階，各パートの WPM・正確さ・前回差・自己ベスト差，今回の分析文を残します．80×24 でも，タイトルへ戻る案内と重なりません．

## 練習メニュー

タイトル画面で «今日の訓練»（一覧の先頭．`M` でも可）を選ぶと，今日の練習メニューを開きます．段の選び方，レベル，卒業の条件は[訓練機能](training.ja.md#練習メニュー)に書きました．この節では段の進め方を説明します．

### 段を進める

`↑`/`↓` で段を選び，`Enter` で始めます．ふつうは上から順に進めますが，どの段からでも始められます．新しい段の前には，目的・達成すること・訓練の内容・コツを説明します．意識すること・卒業の条件・選んだ理由と，分かる場合は具体的な今回の線も示します．この画面は自動では進みません．`Enter` でカウントダウンへ進み，`Esc` でその段をやめます．ほかのキーでは何もしません．段は，その段のモードと設定で，メニューに示した分数だけ行います．設定はその回だけに使い，設定ファイルは変えません．個別の訓練の升目でも，キー選択がある場合は選択後に同じ説明を出します．結果から同じ訓練をもう一度始めるときは，説明を出さずにカウントダウンへ進みます．

仕上げの段は `burst` 3 本です．1 本ごとに `Enter` で次の 1 本を始め，3 本目を終えた時点で段を終えたことになります．各段の結果画面では，`Enter` で次の段へ進み，`Esc` でメニューの実行を終えます．メニューの段のカウントダウン中やプレイ中の `Esc` は，通常のセッションと同じく先に確かめます．1 回目でプレイ中は `もう一度 Esc でやめる（この段は記録しません）`（カウントダウン中は `もう一度 Esc で中断`）と表示し，2 秒以内の 2 回目でその段を保存せずにやめ，メニューの実行を終えます．ほかのキーか時間切れで 1 回目を取り消します．終えた段にはメニュー画面で `済` の印が付きます．`済` の段をもう一度遊ぶとセッションは保存しますが，メニューの段としては 2 度数えません．

1 段以上終えた後に `Esc` で抜けたとき，または最後の段を終えたときは，先にメニューのまとめ画面を出します．`Enter`・`Space`・`Esc` でメニュー画面へ戻ります．

### メニューの中の現在地

各段の前のカウントダウン画面と，段を終えた後の結果画面には，今日のメニュー全体を 1 行で出します．各段は短い名前（処方の段は `遷移` のような練習の要素，固定の段は役割）と分数で並べ，終えた段に `✓`，これから始める段（結果画面では `Enter` で次に始まる段）に `▶` を付けます．行の終わりには現在の段の位置と残りの分数を出します．残りは，まだ終えていない段（印の付いた段を含む）の分数の合計です．

### 結果画面のメニューの行

メニューの段の結果画面では，操作の案内の上に 2 行足し（上がメニューの行，その下が進み具合の行），案内は `[Enter] 次の段    [Esc] メニュー` になります．同じメニューのウォームアップを終えた後の結果画面の下端（80×24）:

```text
│  💾 DB に保存しました → 行 #1                                                │
│                                                                              │
│  ✓ウォームアップ › ▶遷移 5 › 遷移 4 › 確認 3 › 仕上げ 2  段 2/5 · 残り 14 分 │
│  [Enter] 次の段    [Esc] メニュー                                            │
└──────────────────────────────────────────────────────────────────────────────┘
```

ウォームアップには卒業の条件が無いので，メニューの行は空です．処方の段では次のようになります．

```text
メニュー 2/5 先読みを広げる ② — 卒業の条件: 語頭の遅れが自分の中央値以下の回を 3 回続ける — この回: 確認段の後で判定
```

窓が狭いときは，段の番号と名前を先に省きます．«この回» は次のどれかです．

- `満たした 2/3`・`満たさない 0/3`・`判定できない 1/3`: この回の結果と，そのレベルで必要な回数に対する連続の回数
- `卒業 → レベル 3`・`卒業 → 維持`
- `確認段の後で判定`: 同じ回の確認段で判定する条件で，確認段をまだ終えていないとき
- `今日の確認は日本語なので判定は次回`（または英語）: その日の確認段が別の言語のとき

この段で取った参考の判定が «改善» なら，`；改善（参考．対照なし）` を足します．確認段そのものには卒業の条件が無いので，確認段の行には，その確認段で判定した処方を `この確認で判定: 先読みを広げる 満たした 2/3，間隔をそろえる 満たさない 0/3` のように並べます．

### 目標の表示

個別訓練の表の «ふつう» 以外の行は，それぞれ 1 つの技能を鍛えます．打っている間はその技能を目標として表示します．今日の練習の段（升目がその行にある段）でも，表から始めた回でも同じです．ウォームアップと確認の段は «ふつう» の升目なので従来の画面のままで，ベンチ，リプレイ，ウォームアップ単体も同じです．プレイ画面には目標の線 `┃` を引いたメーターの行が加わり，コンボ・誤入力・正確さの行は目標についての補足に替わります．この 2 行は今日の練習でも個別訓練でも同じ形です．メーターは打鍵ごとに（重なりの行はキーを離すたびにも）更新し，目標を満たしていれば緑，線に近ければ黄，外れていれば赤で描きます．目標を割っても途中で終わりません．ライフ制ではなく，最後まで打ちます．

**結果画面**は段の名前（個別訓練では `立ち直り × 単語` のような升目の名前）を題にした枠から始まり，値を大きな数字で，判定をその横に出します．その下に WPM・CPS・正確さ・単語数・誤入力・最大連続正解を 1 行にまとめて控えめに出します．今日の練習の段は進み具合（`3 回連続: 2/3`）を足し，メニューの行と進み具合の行を下端に残します．個別訓練ではその代わりに，同じ升目の前回と自己ベストとの差を出します．たとえば `前回 1.42  ▲ 0.07 改善`，`★ 自己ベスト更新（これまで 1.38）` です．▲ は常に良い向き，▼ は悪い向きなので，低いほど良い行では値が小さくなると ▲ です．その升目の初回は `この升目の初回です（比べる回はまだありません）` と出します．前回と自己ベストは，その升目の直近 200 回までを読んで求めます．端末画像を使えて幅が 120 桁以上あるときは，目標の値をいちばん大きな画像のカードとして上に置き，判定と比較をその横に，WPM・CPS・正確さはカードにせず控えめな 1 行に下げます．

**上段 — 今回の練習．** 予定した段ごとに 1 行で，`段`，練習した言語，`処方・レベル`（レベルは ①②③），`今回`，`前回差`，`卒業の条件` を並べます．

- `今回` は，その処方の卒業の条件に使う値です（例: 語頭の遅れの `1.48`，`412 ms`，`18%`）．ウォームアップ・確認・仕上げは net WPM です．合否で決まる値（正確さの関門，ペーサー目標，R3，キーボードの補助）は `満たした` か `満たさない` と出します．
- `前回差` は，同じ言語・同じ処方・同じレベルの直前の回との差です．緑の `▲` は良くなった，赤の `▼` は悪くなった，`±` は変わらないことを示します．小さいほど良い値は，下がったときに `▲` です．合否の値には差を出しません．
- `卒業の条件` は連続の回数を `●●○ 2/3` のように点で示します．この回で卒業した段は，太字の緑で `●●● → ③ へ` または `●●● → 維持` と出します．

**中段 — 今のスキル．** `今のスキル — 英語（確認段から．7 回移動中央値と比べる）`．その回の確認段を終えた後にだけ表示し，それまでは `確認段を終えると表示` と出します．構成ごとに 1 行で，`段`（現在の閾値での段），`今回`，`前回差`，`移動中央値`，`▁▂▃▄▅▆▇` で描いた `28 日` の折れ線，`傾向`（`上向き`・`横ばい`・`下向き`）を並べます．その回に値が無い構成は `—（データなし）` と出し，0 にはしません．各値の定義は[スキルの推移](analysis.ja.md#スキルの推移)にあります．

最後の 2 行は出どころの違う値を分けて出します．

- `総合（練習から）: C 3.40（前回 C 3.30）` — その回の確認段の値から，通常の総合の式で求めた値です．3 分の確認段 1 回から出した練習の値です．
- `正式の段（ベンチ 英語，11/12）: C` — コーチのタブと同じくベンチから求めた段で，結果が 3 回未満なら `（暫定）` が付きます．正式の段を変えるのはベンチだけです．練習からの総合が良くても昇段しません．

**下段 — 今日の変化．** 最大 4 行で，レベルの変化，入れ替えと休止，判定，ふだんの変動を超えた変化，ベンチの案内の順に並べます．例: `英 先読みを広げるがレベル ② へ`，`英 先読みを広げる: 変化なし（参考．対照なし）．次回から句を先読みするへ入れ替え`，`英 正確さの関門: 改善（参考．対照なし）`，`先読み: ふだんの変動を超えて改善（-0.06，ふだんの変動 ±0.04）`，`ベンチから 5 日．あと 2 日で再測定を勧めます`．R3 による遷移の判定は `効いた（R3．対照つき）` または `効いていない（R3）` と書きます．

端末画像が使えて窓が 120×29 セル以上あるときは 28 日の折れ線を画像で描き，37 行以上あれば練習からの総合の段のバッジも足します．それ以外はすべて文字で描くため，80×24 の端末でも値はすべて残ります．

## セッション履歴

完了したセッションは，ローカルの SQLite データベースに保存されます．既定のファイルは `~/.local/share/rs-typing-trainer/sessions.db` です．別の場所を使うには，設定の `storage.db_path` を指定します．従来の `metrics.db_path` も使えますが，両方があれば `storage.db_path` が優先されます．

新しい既定ファイルが無く，`~/.cache/rs-typing-trainer/sessions.db` が有る場合は，旧データベースを新しい場所へコピーし，旧ファイルも残します．コピーした起動時だけ，タイトル画面に通知します．保存先を設定した場合や，両方の既定ファイルが有る場合はコピーしません．

タイトル画面または結果画面で `H` を押すと履歴を開きます．一覧には日時・種類・内容・言語・配列・WPM・正確さ・時間を表示し，端末が狭くなると配列，言語，時間の順に省きます．v1 取込・練習・ベンチは種類で区別します．同じシリーズ・版のベンチパートは，次のパートが前のパートの終了から 30 分以内に始まれば 1 回にまとめます．`Enter` で保存済みのパートを開閉し，途中で終えた回もそのまま表示します．

`Tab` はすべて／練習／ベンチ，`M` は種類・言語・期間で絞り込んだ後に記録のあるモード，`L` はすべて／`en`／`ja`，`P` は全期間／30 日／7 日を切り替えます．`S` は新しい日時，古い日時，WPM，正確さの順に切り替えます．WPM 順の順位は，練習モードまたはベンチのパートを 1 つに絞ったときだけ表示します．順位には得点対象の記録だけを数え，ベンチはシリーズとパートごとに分けます．

詳細には従来の結果図に加え，記録にあるモード・言語・配列・誤打の扱い・補助・キーの絞り込み・ベンチ ID・語数・最大コンボを表示します．同じ条件の自己ベスト WPM と，直前の回からの差も示します．`R` は v2 セッションをアプリ内で再生し，`E` は `.ttrec` へ書き出します．打鍵ログの無い v1 取込には，この 2 操作を表示しません．詳細から戻っても，選択位置・開いたベンチの回・絞り込みを保ちます．一覧を閉じると，履歴を開いたタイトルまたは直前の結果へ戻ります．

## コーチと段階

`A` で分析画面を開きます．タブは今日・コーチ・推移・キーボード・遷移・指・手・ベンチ・スキルの順です．先頭の今日のタブは，今日のメニューの段・個別の練習・過去 7 日の平均と比べた合計をまとめます（[今日のタブ](analysis.ja.md#今日のタブ)）．開いた時はコーチのタブです．英語・日本語の現在の段階，直前の adaptive の処方結果，具体的な伸びしろ 1〜3 件，判定できた習慣を順に示します．広い端末では総合の段階を色付きの大きなバッジで描き，小さい端末では通常の文字へ戻します．色だけに頼らず段階の文字と値を残します．正式・暫定・仮・仮（難しさ未補正）の出所，根拠の件数，データ不足を明記します．`T` で最近の記録から作った目標候補を開き，`Enter` で選んだ目標を保存すると，そこまでの差を最初の段に表示します．

個別の訓練の画面では，表の上に英語・日本語の段階を小さく表示します．ベンチ A または C の終了後は，該当言語の正式・暫定の段階と昇格・降格を結果画面へ出します．通常の練習では段階の変化を出しません．完了した各セッションの結果には，その回だけの記録から求めた最も目立つ気づきを示すことがあります．`[display].feedback = "summary"` は 1 行，`"detailed"` は最大 3 行です．根拠が足りなければ表示しません．

## 設定

`--config` を省略すると，`./config.toml`，`~/.config/rs-typing-trainer/config.toml` の順で最初に存在するファイルを読みます．どちらも無い場合は既定値を使います．`--lang` は `[general] lang` より優先されます．従来の `[game]`，`[characters]`，`[metrics]` も使えますが，対応する v2 セクションがあれば v2 側を優先します．

`item_timeout_seconds = 0` は 1 項目の制限時間を無効にし，タイマーも隠します．`sentence` は設定値にかかわらずこの制限時間を使わず，`phrase` は単語モードと同じセッション時間・制限時間に従います．`mode.keys` が空なら，`words`，`romaji`，`sentence` ではキーで絞り込みません．`phrase` にはキー選択がありません．`random` と `ngram` ではキー選択画面で選択を促します．

設定画面では，練習レイアウト・入力レイアウト・物理配置・`auto` を含むキーボード表示・キーボードの見た目・問題文の表示・端末画像・言語・誤入力の扱い・結果の気づきを変更できます．保存時も既存のコメントと関係のない TOML 項目を維持します．全キーと既定値は[設定リファレンス](configuration.ja.md)，訓練機能は[訓練機能](training.ja.md)，読み替え・利用者定義レイアウト・Release イベントは[キーボードの配列と表示](keyboard.ja.md)を参照してください．

## 終了後も端末の状態がおかしい場合

通常終了・エラー・パニックからの復帰では，キーボードプロトコルの設定を戻し，残った入力を短時間読み捨て，代替画面を抜けてカーソルを表示してから raw モードを解除します．回復できない形でプロセスが停止し，終了後も入力や表示がおかしい場合は，`reset` と入力して `Enter` を押し，端末の状態を戻してください．
