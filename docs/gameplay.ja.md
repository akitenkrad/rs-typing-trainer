# rs-typing-trainer の遊び方

## セッションの開始

`rs-typing-trainer` または `cargo run --release` を実行すると，タイトル画面が開きます．表示言語の既定は英語です．日本語にするには `--lang ja` を使います．`--config PATH` を指定すると，通常の検索先の代わりにその設定ファイルを読みます．

サブコマンドなしの起動は `rs-typing-trainer play` と同じです．`replay FILE` は可搬記録を再生し，`stats` は保存済みセッションを分析し，`export SESSION_ID [-o FILE]` は v2 セッションを `.ttrec` として書き出します．`-o` を省略すると標準出力を使います．リプレイは記録ファイルだけを読みます．詳しくは[リプレイ](replay.ja.md)を参照してください．

## 操作

| 画面 | キー | 動作 |
|---|---|---|
| タイトル | `↑` / `↓`（`k` / `j`） | メニューの選択を移動 |
| タイトル | `Enter` | 選択中の項目を実行 |
| タイトル | `Space` | モード選択を直接開く |
| タイトル | `H` | 履歴を開く |
| タイトル | `B` | `bench-v1` の選択画面を開く |
| タイトル | `A` | 分析を開く |
| タイトル | `S` | 設定を開く |
| タイトル | `Q` / `Esc` | 終了 |
| モード選択 | `↑` / `↓`（`k` / `j`） | 練習モードを選ぶ |
| モード選択 | `P` | 対応モードのペーサーを切り替える |
| モード選択 | `L` | 適応練習の言語を切り替える |
| モード選択 | `[` / `]` | 先読み項目数を減らす・増やす |
| モード選択 | `Enter` | キー選択またはカウントダウンへ進む |
| ベンチ選択 | `↑` / `↓`（`k` / `j`） | 開始または任意のパート D を選ぶ |
| ベンチ選択 | `Enter` | 選択中の操作を実行 |
| ベンチ選択 | `Space` | ベンチマークを直接開始 |
| ベンチ選択 | `D` | 任意のパート D を直接切り替える |
| ベンチ選択 | `Esc` / `Q` | タイトルへ戻る |
| キー選択 | 矢印キー | キーボード上を移動 |
| キー選択 | `Space` | 現在のキーを切り替える |
| キー選択 | `Tab` | `include` / `only` を切り替える |
| キー選択 | `Enter` | 選択を保存してカウントダウンを始める |
| プレイ | 印字できるキー | 単語を入力 |
| プレイ | `Backspace` | `advance` の誤入力モードで 1 文字戻る |
| プレイ | `Esc` | 中断してタイトルへ戻る |
| 結果 | `Space` / `Enter` | 次のセッションを開始 |
| 結果 | `H` | 履歴を開く |
| 結果 | `Q` / `Esc` | 終了 |
| 履歴 | `↑` / `↓`（`k` / `j`） | 選択を移動 |
| 履歴 | `PgUp` / `PgDn` / `Home` / `End` | 一覧内を大きく移動 |
| 履歴 | `S` | 並び順を切り替える |
| 履歴 | `Enter` | セッションの詳細を表示 |
| 履歴 | `Esc` / `Q` | タイトルへ戻る |
| 履歴詳細 | `Space` / `Enter` / `Esc` | 履歴へ戻る |
| 履歴詳細 | `Q` | 終了 |
| 設定 | `↑` / `↓`（`k` / `j`） | 設定項目を選ぶ |
| 設定 | `←` / `→`（`h` / `l`） | 選択した値を変更する |
| 設定 | `Enter` | 保存してタイトルへ戻る |
| 設定 | `Esc` / `Q` | 保存せずにタイトルへ戻る |

単語が入る途中と出る途中の各約 200 ms は，打鍵を捨てます．1 つの単語を終えた打鍵が，次の単語の入力として数えられるのを防ぐためです．

## プレイ画面の配置

プレイ画面は，時間・WPM・項目数・ペースをヘッダに表示します．その下に画面上のキーボードと指の色帯を置き，有効な場合は項目タイマー，続いて連続正解・誤入力・正確さを表示します．出題は残りの領域で左右・上下に中央寄せします．ローマ字は表記・かな・ローマ字の 3 段の行頭をそろえ，`sentence` と `endurance` は折り返した本文全体を中央に置きます．次の項目と操作説明は最下行に残します．

高さが足りない場合は，キーボード，連続正解などの行，項目タイマーの順に省き，出題と操作説明は残します．`keyboard.show = "hidden"` では，高さにかかわらずキーボード領域を省いて詰めます．

## セッション履歴

完了したセッションは，ローカルの SQLite データベースに保存されます．既定のファイルは `~/.local/share/rs-typing-trainer/sessions.db` です．別の場所を使うには，設定の `storage.db_path` を指定します．従来の `metrics.db_path` も使えますが，両方があれば `storage.db_path` が優先されます．

新しい既定ファイルが無く，`~/.cache/rs-typing-trainer/sessions.db` が有る場合は，旧データベースを新しい場所へコピーし，旧ファイルも残します．コピーした起動時だけ，タイトル画面に通知します．保存先を設定した場合や，両方の既定ファイルが有る場合はコピーしません．

タイトル画面で `H` を押すと履歴を開きます．`S` を押すたびに，新しい日時，古い日時，WPM，正確さ，最大連続正解，完了した単語数の順で並び替えます．得点による並び順では順位も表示します．`Enter` で，誤入力の分布と反応時間の分布を含む元の結果を開きます．

## 設定

`--config` を省略すると，`./config.toml`，`~/.config/rs-typing-trainer/config.toml` の順で最初に存在するファイルを読みます．どちらも無い場合は既定値を使います．`--lang` は `[general] lang` より優先されます．従来の `[game]`，`[characters]`，`[metrics]` も使えますが，対応する v2 セクションがあれば v2 側を優先します．

`item_timeout_seconds = 0` は 1 項目の制限時間を無効にし，タイマーも隠します．`sentence` は設定値にかかわらず，この制限時間を使いません．`mode.keys` が空なら，`words`，`romaji`，`sentence` ではキーで絞り込みません．`random` と `ngram` ではキー選択画面で選択を促します．

設定画面では，練習レイアウト・入力レイアウト・物理配置・`auto` を含むキーボード表示・言語・誤入力の扱いを変更できます．保存時も既存のコメントと関係のない TOML 項目を維持します．全キーと既定値は[設定リファレンス](configuration.ja.md)，訓練機能は[訓練機能](training.ja.md)，読み替え・利用者定義レイアウト・Release イベントは[キーボードの配列と表示](keyboard.ja.md)を参照してください．
