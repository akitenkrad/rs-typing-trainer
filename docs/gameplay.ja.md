# rs-typing-trainer の遊び方

## セッションの開始

`rs-typing-trainer` または `cargo run --release` を実行すると，タイトル画面が開きます．表示言語の既定は英語です．日本語にするには `--lang ja` を使います．`--config PATH` を指定すると，通常の検索先の代わりにその設定ファイルを読みます．

サブコマンドなしの起動は `rs-typing-trainer play` と同じです．`replay FILE` は可搬記録を再生し，`stats` は保存済みセッションを分析し，`export SESSION_ID [-o FILE]` は v2 セッションを `.ttrec` として書き出します．`-o` を省略すると標準出力を使います．リプレイは記録ファイルだけを読みます．詳しくは[リプレイ](replay.ja.md)を参照してください．

## 操作

| 画面 | キー | 動作 |
|---|---|---|
| タイトル | `↑` / `↓`（`k` / `j`） | メニューの選択を移動 |
| タイトル | `Enter` | 選択中の項目を実行 |
| タイトル | `Space` | モード選択を直接開く |
| タイトル | `H` | 履歴を開く |
| タイトル | `B` | `bench-v1` の選択画面を開く |
| タイトル | `A` | 分析を開く |
| タイトル | `S` | 設定を開く |
| タイトル | `Q` / `Esc` | 終了 |
| モード選択 | `↑` / `↓`（`k` / `j`） | 練習モードを選ぶ |
| モード選択 | `P` | 対応モードのペーサーを切り替える |
| モード選択 | `L` | 適応練習の言語を切り替える |
| モード選択 | `[` / `]` | 先読み項目数を減らす・増やす |
| モード選択 | `Z` | 問題文の表示を大きな文字と通常の文字で切り替える（モードの開始時に保存） |
| モード選択 | `Enter` | キー選択またはカウントダウンへ進む |
| ベンチ選択 | `↑` / `↓`（`k` / `j`） | 開始または任意のパート D を選ぶ |
| ベンチ選択 | `Enter` | 選択中の操作を実行 |
| ベンチ選択 | `Space` | ベンチマークを直接開始 |
| ベンチ選択 | `D` | 任意のパート D を直接切り替える |
| ベンチ選択 | `Esc` / `Q` | タイトルへ戻る |
| キー選択 | 矢印キー | キーボード上を移動 |
| キー選択 | `Space` | 現在のキーを切り替える |
| キー選択 | `Tab` | `include` / `only` を切り替える |
| キー選択 | `Enter` | 選択を保存してカウントダウンを始める |
| プレイ | 印字できるキー | 単語を入力 |
| プレイ | `Backspace` | `advance` の誤入力モードで 1 文字戻る |
| プレイ | `Esc` | 中断してタイトルへ戻る |
| 結果 | `Space` / `Enter` | 次のセッションを開始 |
| 結果 | `H` | 履歴を開く |
| 結果 | `Q` / `Esc` | 終了 |
| 履歴 | `↑` / `↓`（`k` / `j`） | 選択を移動 |
| 履歴 | `PgUp` / `PgDn` / `Home` / `End` | 一覧内を大きく移動 |
| 履歴 | `S` | 並び順を切り替える |
| 履歴 | `Enter` | セッションの詳細を表示 |
| 履歴 | `Esc` / `Q` | タイトルへ戻る |
| 履歴詳細 | `Space` / `Enter` / `Esc` | 履歴へ戻る |
| 履歴詳細 | `Q` | 終了 |
| 設定 | `↑` / `↓`（`k` / `j`） | 設定項目を選ぶ |
| 設定 | `←` / `→`（`h` / `l`） | 選択した値を変更する |
| 設定 | `Enter` | 保存してタイトルへ戻る |
| 設定 | `Esc` / `Q` | 保存せずにタイトルへ戻る |

単語が入る途中と出る途中の各約 200 ms は，打鍵を捨てます．1 つの単語を終えた打鍵が，次の単語の入力として数えられるのを防ぐためです．

## プレイ画面の配置

プレイ画面は上から順に，ヘッダ（時間・WPM・項目数・ペース），キーボード，項目タイマーのバー，連続正解・誤入力・正確さの行，出題，最下行の次の項目と操作説明です．出題は連続正解の行の直下から始め，キーボードより下の領域の上下中央には寄せません．左右は中央のままです．

`display.prompt_style` で問題文の描き方を `large`（既定）と `normal` から選びます．設定画面では «問題文の表示»（値は «大きな文字» と «通常の文字»）として表示し，モード選択画面の `Z` でも切り替えられます．

**大きな文字** は，打っている項目を同梱した東雲ビットマップフォントで描きます．4個のフォントドットを端末の4分割ブロック文字1セルへ変換するため，12ドットの全角1字は6×6セル，16ドットは8×8セルです．大きな字形のブロックと，その前後の通常の大きさの行の間には 1 行ずつ空きを入れます．ラベルは独立した行にせず，対応するブロックの左隣の列，ブロックの最上段に置きます．

- 英語の項目モード: 大きな項目と下線 `▔` のカーソル．場所があれば，空き行のあとに補助行（ロック中，誤入力の内容，この単語の誤入力数，結果）を出します．
- ローマ字モード: 大きな表記 → 空き → かな（太字・強調色．今の音を反転）→ 空き → 大きなローマ字とカーソル．ラベル（表記・かな・ローマ字）は左の列にそろえ，各ブロックは同じ列から始めます．
- `sentence` と `endurance`: 現在位置の前後を大きな窓で表示し，カーソル → 空き → 全文（通常の大きさ．今の位置を反転）の順に並べます．日本語の短文は上のローマ字と同じ並びのあと，空きを挟んで全文の表記・かな・ローマ字の 3 段を出します．

高さが足りないときは空き行から先に詰め，字形は削りません．ペーサーとゴーストの印は，対応する大きな文字の上に置きます．ブラインドモードでは入力済みの大きな字形を空白にします．大きな文字は，外枠の内側に左右 1 列ずつの余白を残して描きます．端末のフォントに4分割ブロック文字（U+2596〜U+259F と U+2580〜U+2590）が必要です．端末が1セルより幅の広い代替フォントで描くと大きな文字の行が枠より広く見えることがあり，その場合は `display.prompt_style = "normal"` で避けられます．フォントに無い文字（JIS X 0208 と ASCII・半角カナの範囲外）は，その字だけ通常の大きさで大きな枠の中央に置きます．

大きな文字の大きさは端末に合わせて自動で選びます．16ドット＋選択したキーボード，12ドット＋同じキーボード，12ドット＋簡素なキーボード，12ドット＋キーボード非表示の順に試し，どれも入らなければ通常の文字で（入るキーボードと一緒に）表示します．出題と操作説明は省きません．`keyboard.show = "hidden"` では，高さにかかわらずキーボード領域を省いて詰めます．

**通常の文字** は，端末の文字の大きさのまま，丸角の罫線（`╭╮╰╯`）で囲んだカードに入れ，連続正解などの行の直下・左右中央に置きます．カードの内側には左右 2 列・上下 1 行の余白を取ります．未入力の文字は明るい色の太字，今の文字は反転（誤入力の点滅中は赤の背景），入力済みの文字は落ち着いた色です．項目モード（words・random・ngram・adaptive・unlock・rhythm・burst）は文字の間に 1 セルの空きを入れ，カーソル `▲` を今の文字の真下に置きます．ローマ字モードは左の列にラベル（薄い色），右の列に本文を置く 2 列で，表記（太字）・かな・ローマ字の 3 段を 1 行ずつ空けて並べ，今の音・今の文字を反転します．短文は本文をカードの中で折り返し，今の行を明るく，それ以外の行を少し暗くし，今の行の直下にカーソルの行を置きます．日本語の短文は上の 3 段で，各段を折り返します．ペーサーとゴーストの印は文字の真上の行に置き，補助のメッセージはカードの下に出します．通常の文字ではキーボードよりカードを優先し，キーボードを先に簡素化・非表示にします．それでも足りない小さな端末では，カードの空き行・余白・枠の順に省き，文字は最後まで残します．

## セッション履歴

完了したセッションは，ローカルの SQLite データベースに保存されます．既定のファイルは `~/.local/share/rs-typing-trainer/sessions.db` です．別の場所を使うには，設定の `storage.db_path` を指定します．従来の `metrics.db_path` も使えますが，両方があれば `storage.db_path` が優先されます．

新しい既定ファイルが無く，`~/.cache/rs-typing-trainer/sessions.db` が有る場合は，旧データベースを新しい場所へコピーし，旧ファイルも残します．コピーした起動時だけ，タイトル画面に通知します．保存先を設定した場合や，両方の既定ファイルが有る場合はコピーしません．

タイトル画面で `H` を押すと履歴を開きます．`S` を押すたびに，新しい日時，古い日時，WPM，正確さ，最大連続正解，完了した単語数の順で並び替えます．得点による並び順では順位も表示します．`Enter` で，誤入力の分布と反応時間の分布を含む元の結果を開きます．

## 設定

`--config` を省略すると，`./config.toml`，`~/.config/rs-typing-trainer/config.toml` の順で最初に存在するファイルを読みます．どちらも無い場合は既定値を使います．`--lang` は `[general] lang` より優先されます．従来の `[game]`，`[characters]`，`[metrics]` も使えますが，対応する v2 セクションがあれば v2 側を優先します．

`item_timeout_seconds = 0` は 1 項目の制限時間を無効にし，タイマーも隠します．`sentence` は設定値にかかわらず，この制限時間を使いません．`mode.keys` が空なら，`words`，`romaji`，`sentence` ではキーで絞り込みません．`random` と `ngram` ではキー選択画面で選択を促します．

設定画面では，練習レイアウト・入力レイアウト・物理配置・`auto` を含むキーボード表示・キーボードの見た目・問題文の表示・言語・誤入力の扱いを変更できます．保存時も既存のコメントと関係のない TOML 項目を維持します．全キーと既定値は[設定リファレンス](configuration.ja.md)，訓練機能は[訓練機能](training.ja.md)，読み替え・利用者定義レイアウト・Release イベントは[キーボードの配列と表示](keyboard.ja.md)を参照してください．

## 終了後も端末の状態がおかしい場合

通常終了・エラー・パニックからの復帰では，キーボードプロトコルの設定を戻し，残った入力を短時間読み捨て，代替画面を抜けてカーソルを表示してから raw モードを解除します．回復できない形でプロセスが停止し，終了後も入力や表示がおかしい場合は，`reset` と入力して `Enter` を押し，端末の状態を戻してください．
